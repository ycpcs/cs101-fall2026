# Practice 1: Count Up

Write a program that asks for a positive integer `n` and prints the integers from 1 through `n`, one per line.

### Example output

<pre>
Enter a positive integer: <b>5</b>
1
2
3
4
5
</pre>

### Starter code

<pre>
#include &lt;stdio.h&gt;

int main()
{
    int n;

    printf("Enter a positive integer: ");
    scanf("%i", &amp;n);

    // Write the for loop here

    return 0;
}
</pre>

## Practice 4: Multiplication by Repeated Addition

Ask for two non-negative integers, `a` and `b`. Compute `a * b` by adding `a` to an accumulator exactly `b` times.

Do not use the `*` operator to calculate the product.

### Example output

<pre>
Enter two non-negative integers: <b>6 4</b>
The product is 24.
</pre>

### Starter code

<pre>
int product = 0;

for (int count = 0; count &lt; b; count++) {
    // Update product here
}
</pre>

### Think about it

How many times does the loop execute when `b` is 0? Why is the value of `product` still correct?

## Practice 8: Fix the Bugs

The following program is supposed to print the numbers 1 through 5 and then print their sum. It contains several mistakes. Find and correct them.

<pre>
#include &lt;stdio.h&gt;

int main()
{
    int sum;

    for (int i = 1; i &gt;= 5; i--) {
        printf("%i\n", i);
        sum = i;
    }

    printf("Sum: %i\n", sum);

    return 0;
}
</pre>

Look carefully at:

* The initial value of the accumulator
* The loop condition
* The direction of the update
* How the accumulator is updated
* Whether the loop will terminate

## Practice 10: Alternating Series

Ask the user for a positive integer `n`. Compute the first `n` terms of this series:

<pre>
1/2 - 1/4 + 1/6 - 1/8 + 1/10 - ...
</pre>

For each iteration, derive the denominator from the loop variable. Use an `if`/`else` statement to choose whether the term is positive or negative.

### Plan the first five iterations

| `i` | Denominator | Sign |   Term |
| --: | ----------: | :--: | -----: |
|   1 |           2 |  `+` |  `1/2` |
|   2 |           4 |  `-` | `-1/4` |
|   3 |           6 |  `+` |  `1/6` |
|   4 |           8 |  `-` | `-1/8` |
|   5 |          10 |  `+` | `1/10` |

### Example output

<pre>
Enter the number of terms: <b>4</b>
The sum is 0.291667.
</pre>

### Requirements

* Use a `double` accumulator initialized to `0.0`.
* Make the loop execute exactly `n` times.
* Compute the denominator from `i`.
* Use `i % 2` to determine the sign.

## Practice 12: Full Lecture Rehearsal

Write one program that:

1. Reads a positive integer `n`.
2. Prints the integers from 0 through `n - 1`.
3. Prints the integers from `n` down through 1.
4. Computes the sum of the integers from 1 through `n`.
5. Computes `3 * n` using repeated addition instead of multiplication.
6. Prints a closing message.

### Example output

<pre>
Enter a positive integer: <b>4</b>

Counting up: 0 1 2 3
Counting down: 4 3 2 1
Sum from 1 through 4: 10
3 times 4: 12

Loop practice complete.
</pre>

Use separate `for` loops for the different tasks. Choose the appropriate loop recipe for each task.
