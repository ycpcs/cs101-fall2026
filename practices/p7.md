# Practice 1: Count with a While Loop

Ask the user for a positive integer `n`. Use a `while` loop to print the integers from 1 through `n`.

### Example output

<pre>
Enter a positive integer: <b>5</b>
1
2
3
4
5
</pre>

### Starter code

<pre>
#include &lt;stdio.h&gt;

int main()
{
    int n;
    int count;

    printf("Enter a positive integer: ");
    scanf("%i", &amp;n);

    count = 1;

    // Write the while loop here

    return 0;
}
</pre>

### Remember

A `while` loop needs:

1. Initialization before the loop
2. A condition that controls the loop
3. An update inside the loop body

## Practice 5: Repeat Until the User Stops

Write a program that repeatedly asks the user for an integer and prints its square.

After each calculation, ask whether the user wants to continue. The program should stop when the user enters 0.

### Example output

<pre>
Enter an integer: <b>5</b>
The square is 25.
Continue? (1 for yes, 0 for no): <b>1</b>

Enter an integer: <b>8</b>
The square is 64.
Continue? (1 for yes, 0 for no): <b>0</b>

Goodbye!
</pre>

### Starter code

<pre>
int keep_going = 1;

while (keep_going == 1) {
    int value;
    int answer;

    printf("Enter an integer: ");
    scanf("%i", &amp;value);

    // Print the square

    printf("Continue? (1 for yes, 0 for no): ");
    scanf("%i", &amp;answer);

    // Update keep_going when the user enters 0
}
</pre>

### Think about it

Why is a `while` loop more appropriate than a `for` loop for this program?

## Practice 12: Improve the Coding Style

The following program is difficult to read. Rewrite it using good indentation, spacing, and meaningful identifier names.

Do not change what the program does.

<pre>
#include &lt;stdio.h&gt;
int main(){int x;int y=0;printf("Enter a number: ");scanf("%i",&amp;x);while(x&gt;0){y=y+x;x=x-1;}printf("Result: %i\n",y);return 0;}
</pre>

### Coding-style requirements

* Place each statement on its own line.
* Indent statements inside `main`.
* Indent statements inside the `while` loop one additional level.
* Add useful spaces around operators.
* Replace `x` and `y` with meaningful names.
* Place curly braces consistently.

## Practice 14: Full Lecture Rehearsal

Write a program that repeatedly asks the user for an integer.

For every nonzero integer:

* Print whether the number is positive or negative.
* Print whether the number is even or odd.
* Add the number to a running total.
* Ask for another integer.

The program should stop when the user enters 0. After the loop, print the total.

### Example output

<pre>
Enter an integer (0 to stop): <b>7</b>
7 is positive.
7 is odd.

Enter an integer (0 to stop): <b>-4</b>
-4 is negative.
-4 is even.

Enter an integer (0 to stop): <b>3</b>
3 is positive.
3 is odd.

Enter an integer (0 to stop): <b>0</b>

The total is 6.
Program complete.
</pre>

### Requirements

* Use a `while` loop.
* Use at least one `if`/`else` statement inside the loop.
* Initialize all variables before they are used.
* Update the value controlling the loop.
* Use meaningful identifier names.
* Use consistent indentation and curly-brace placement.
