# Short Concept Answers

1. Functions that take array parameters usually need a `size` parameter because arrays do not automatically provide their length when passed to a function. The `size` parameter tells the function how many elements to process.

2. When an `int` variable is passed to a function, its value is copied, so changes inside the function do not affect the original variable. When an array is passed, the function accesses the original array, so changes to its elements affect the original array.

3. Yes, changing `array[0]` inside a function changes the original array because the array parameter refers to the same elements in memory as the original array.

4. `const double array[]` means that the array elements are treated as constant doubles inside the function. The function can read the elements but cannot modify their values.

5. Array parameters use empty brackets `[]` because functions can accept arrays of different sizes. The number of elements does not need to be specified in the parameter declaration, so a separate `size` parameter is usually used.

6. When passing a two-dimensional array to a function, the number of columns must be specified so the function can correctly calculate the memory location of each element. The number of rows can be omitted, but the number of columns must be known.
