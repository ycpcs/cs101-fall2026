# Additional Practice: Conditions and Decisions

## Coding Practice

### 1. Temperature Check

Write a program that reads a temperature as a `double`.

* If the temperature is at least `90.0`, print `That's hot!`
* Otherwise, print `Not too hot today.`

Example:

<pre>
Enter the temperature: <b>94.5</b>
That's hot!
</pre>

---

### 2. Positive or Negative

Write a program that reads an integer.

* If the number is greater than or equal to `0`, print `Non-negative`
* Otherwise, print `Negative`

Example:

<pre>
Enter an integer:  <b>-7</b>
Negative
</pre>

---

### 3. Passing Grade

Write a program that reads a student's numeric grade as a `double`.

* If the grade is greater than or equal to `60.0`, print `Passing`
* Otherwise, print `Not passing`

Also print the grade with one digit after the decimal point.

Example:

<pre>
Enter the grade:  <b>72.5</b>

Grade: 72.5
Result: Passing
</pre>

---

### 4. Teenager Check

Write a program that reads a person's age as an integer.

A person is a teenager if the age is at least `13` and no more than `19`.

Use the logical AND operator, `&&`, in the condition.

Example:

<pre>
Enter your age:  <b>16</b>
You are a teenager.
</pre>

If the age is outside that range, print:

```text
You are not a teenager.
```

---

### 5. Special Number

Write a program that reads an integer and determines whether it is either `2` or `3`.

Use the logical OR operator, `||`.

Example:

<pre>
Enter an integer:  <b>3</b>
That is a special number.
</pre>

Remember that the condition must compare the variable separately to each value.

---

### 6. Shipping Calculator

Write a program that reads the total cost of an order.

* If the order costs at least `$50.00`, shipping is free.
* Otherwise, shipping costs `$6.99`.

Calculate and print the order cost, shipping cost, and final total. Display all monetary values with two digits after the decimal point.

Example:

<pre>
Enter the order cost:  <b>42.00</b>

Order cost: $42.00
Shipping: $6.99
Final total: $48.99
</pre>

---

### 7. Salary Calculator Extension

Modify the Salary Calculator lab so it also checks the user's input.

The number of hours and the hourly rate must both be non-negative.

Use the following condition:

```c
(hours >= 0.0) && (hourlyRate >= 0.0)
```

If both values are valid, calculate the salary normally.

If either value is negative, print:

```text
Error: Hours and hourly rate cannot be negative.
```

Do not calculate or print salary information when the input is invalid.

# Conditions: Predict the Result

For each expression, determine whether its result is true or false.

Assume:

```c
int age = 18;
int count = 5;
double temperature = 82.5;
```

1. `age == 18`
2. `age != 18`
3. `count < 10`
4. `temperature >= 90.0`
5. `(age >= 13) && (age <= 19)`
6. `(count == 2) || (count == 5)`
7. `!(temperature > 80.0)`

# Debugging Practice

Each code fragment contains an error. Identify and correct it.

## A. Assignment Instead of Equality

```c
if (number = 10) {
    printf("The number is 10.\n");
}
```

---

## B. Missing Parentheses

```c
if age >= 18 {
    printf("Adult\n");
}
```

---

## C. Incorrect OR Expression

```c
if ((number == 2) || 3) {
    printf("The number is 2 or 3.\n");
}
```

---

## D. Incorrect Range Test

```c
if (13 <= age <= 19) {
    printf("Teenager\n");
}
```

---

## E. Semicolon After `if`

```c
if (temperature >= 90.0); {
    printf("That's hot!\n");
}
```

---

## F. Incorrect `else` Syntax

```c
if (grade >= 60.0) {
    printf("Passing\n");
}
else (grade < 60.0) {
    printf("Not passing\n");
}
```
