# Short Concept Answers

1. An array of structs is an array where each element is a structure containing multiple fields. It is similar to an array of integers because elements are accessed using indexes, but each element contains multiple values instead of a single integer.

2. `pts[2].x` accesses the `x` field of the third `Point` struct in the array. The index `[2]` selects the third element, and the dot operator `.` accesses its `x` field.

3. Functions that take arrays of structs usually need a `size` parameter because arrays do not automatically provide their length when passed to a function. The `size` parameter tells the function how many struct elements to process.

4. When a single struct element (`pts[0]`) is passed to a function, its value is copied, so changes inside the function do not affect the original struct. When an entire array (`pts`) is passed, the function accesses the original array, so changes to its elements affect the original array.

5. Yes, changing `pts[0].x` through an array parameter changes the original array because the function accesses the same struct elements in memory as the original array.

6. `struct Point p` passes a copy of a struct to a function, so changes do not affect the original struct. `struct Point *p` passes a pointer to a struct, allowing the function to modify the original struct through that pointer.

7. The dot operator `.` is used to access fields of a struct variable, such as `p.x`. The arrow operator `->` is used to access fields through a pointer to a struct, such as `p->x`.

8. We use `&pts[i]` because the `&` operator gives the memory address of the struct element. This allows a function that expects a pointer to access and modify the original struct.

9. `const struct Point pts[]` means that the struct elements are treated as constant inside the function. The function can read their fields but cannot modify their values through the array parameter.

10. Array-of-struct parameters use empty brackets `[]` because functions can accept arrays of different sizes. The number of elements does not need to be specified in the parameter declaration, so a separate `size` parameter is usually used.

11. Yes, a struct can contain an array of other structs. For example, a `Triangle` struct can contain an array of three `Point` structs using `struct Point pt[3];`.

12. To access the `y` coordinate of the third point in a `Triangle` variable named `tri`, use `tri.pt[2].y`. The index `[2]` selects the third point, and the dot operator accesses its `y` field.
