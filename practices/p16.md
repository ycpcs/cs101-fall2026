# Read the Code

## Practice 1: Basic Structure Pointer

What is the exact output? What does `p` point to?

<pre>
struct Point {
    int x;
    int y;
};

int main(void) {
    struct Point a = {3, 7};
    struct Point *p = &a;

    printf("%i\n", a.x);
    printf("%i\n", p->x);
    printf("%i\n", p->y);

    return 0;
}
</pre>

## Practice 7: Pass by Value vs. Pointer

<pre>

    double x;
    double y;
