# Short Concept Answers

1. A `struct` is a user-defined data type that groups related fields under one name. It helps organize related data and makes it easier to pass or return multiple values together.
2. A struct definition describes the fields and their types. A struct variable is an instance of that type that stores actual values.
3. `struct Point p;` declares a variable named `p` of type `struct Point`.
4. Use the dot operator: `p.x`.
5. Yes. Each struct variable stores its own values independently.
6. All field values are copied from one struct variable to the other. Changing one variable afterward does not affect the other.
7. Yes. A struct can contain fields of different data types, such as `int`, `float`, and `char`.
8. For example, `float calculateArea(struct Rectangle r);` declares a function that accepts a `struct Rectangle` parameter and returns a `float`.
9. Yes. For example, `struct Point movePoint(struct Point p);` declares a function that accepts and returns a `struct Point`.
10. No. The function receives a copy of the struct. Modifying the parameter does not change the original struct.
11. A function returning `float` returns one floating-point value. A function returning `struct Rectangle` returns an entire struct containing all its fields.
12. The function receives a copy of `r`, so the original struct is not automatically changed. The assignment stores the returned struct back into `r`.
13. Yes. For example, `struct Point addPoints(struct Point p1, struct Point p2);` accepts two structs and returns a struct.
14. `struct Point p1 = {2, 3};` creates a struct variable and initializes its fields with 2 and 3. `struct Point p2 = p1;` creates another struct variable and copies the field values from `p1`. The two variables are independent.
