# Practice 1: Read and Repeat

Write a program that asks for one decimal number and prints it with three digits after the decimal point.

### Example output

<pre>Enter a decimal value: <b>6.25</b>
You entered 6.250</pre>

### Starter code

```cpp
#include <stdio.h>

int main()
{
    double value;

    printf("Enter a decimal value: ");
    // Read value here

    // Print value here

    return 0;
}
```

## Practice 4: Temperature Converter

Ask for a temperature in Fahrenheit and convert it to Celsius.

### Formula

```text
celsius = (fahrenheit - 32.0) * 5.0 / 9.0
```

### Example output

<pre>
Enter temperature in Fahrenheit: <b>68</b>
Temperature in Celsius: 20.000
</pre>

### Think about it

Why does the formula use `32.0`, `5.0`, and `9.0` instead of only integers?

## Practice 8: Fix the Bugs

The following program contains several mistakes. Find and correct them.

```cpp
#include <stdio.h>

int main()
{
    double price;
    int quantity;

    printf("Enter the price: ");
    scanf("%f", price);

    printf("Enter the quantity: ");
    scanf("%lf", &quantity);

    printf("Total: %.3i\n", price * quantity);

    return 0;
}
```

Look carefully at:

- The conversion specifier for reading a `double`
- The conversion specifier for reading an `int`
- The use of `&`
- The conversion specifier for printing the result
- The type of the expression `price * quantity`

## Short Concept Questions

1. What is the difference between `int` and `double`?
2. Which conversion specifier reads a `double`?
3. Which conversion specifier prints a `double`?
4. What does `%.3f` mean?
5. What does the `%` arithmetic operator calculate?
6. How do you print a literal percent sign with `printf`?
7. What result does `11 / 4` produce when both values are integers?
8. What result does `11.0 / 4.0` produce?
9. What problem could occur if the second value in a division is zero?
