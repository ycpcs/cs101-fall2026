## Coding Practice

### 1. Changing Variables

Write a program that:

1. Stores `10` in an integer variable named `count`.
2. Adds `5` using `+=`.
3. Increments it using `++`.
4. Subtracts `3` using `-=`.
5. Prints the final value.

Expected output:

```text
Final count: 13
```

---

### 2. Rectangle

Write a program that reads a rectangle's length and width as `double` values. Calculate its area and perimeter.

Use the following formulas:

$$
\text{area} = \text{length} \times \text{width}
$$

$$
\text{perimeter} = 2 \times (\text{length} + \text{width})
$$

Print each result with two digits after the decimal point.

Example:

<pre>
Enter the length: <b>7.5</b>
Enter the width: <b>3.0</b>

Area: 22.50
Perimeter: 21.00
</pre>

---

### 3. Class Average

Write a program that reads three integer test scores and calculates their average as a `double`.

Example:

<pre>
Enter score 1: <b>80</b>
Enter score 2: <b>81</b>
Enter score 3: <b>81</b>

Average: 80.67
</pre>

Use a type cast or a mixed-type expression so that the fractional part of the average is not lost.

---

### 4. Temperature Conversion

Write a program that reads a Fahrenheit temperature as a `double` and converts it to Celsius.

Use the following formula:

$$
C = (F - 32) \times \frac{5}{9}
$$

Example:

<pre>
Enter a Fahrenheit temperature: <b>77</b>
Celsius temperature: 25.0
</pre>

Be careful to avoid integer division.

---

### 5. Distance from the Origin

Write a program that reads the `x` and `y` coordinates of a point and calculates the point's distance from the origin.

Use the following formula:

$$
d = \sqrt{x^2 + y^2}
$$

Remember to include the `math.h` header file:

```c
#include <math.h>
```

C does not use `^` to calculate a power. Calculate \(x^2\) as:

```c
x * x
```

Example:
<pre>
Enter x: <b>3.0</b>
Enter y: <b>4.0</b>

Distance from the origin: 5.00
</pre>

---

### 6. Right-Triangle Extension

Modify the Right Triangle program so that it also calculates the triangle's area and perimeter.

Use the following formulas:

$$
\text{area} = \frac{a \times b}{2}
$$

$$
\text{perimeter} = a + b + \text{hypotenuse}
$$

Print all measurements with one digit after the decimal point.

Example:

<pre>
Enter the length of side 1: <b>3.0</b>
Enter the length of side 2: <b>4.0</b>

Side 1: 3.0
Side 2: 4.0
Hypotenuse: 5.0
Area: 6.0
Perimeter: 12.0
</pre>
