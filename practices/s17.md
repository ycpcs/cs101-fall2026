# Short Concept Answers

1\. Composition is the programming technique of building a more complex data type using simpler data types. It is useful because it allows existing structures and functions to be reused.

2\. A struct containing another struct can be initialized using nested braces. For example, `struct Player p = \{\{2, 3\}, 100\};` initializes the player's location with row 2 and column 3, and hit points with 100.

3\. `p.loc.row` accesses the `row` field directly when `p` is a structure variable, while `p->loc.row` accesses the same field when `p` is a pointer to a structure.

4\. `&player->loc` gets the memory address of the `loc` field inside the structure pointed to by `player`. It can be passed to a function expecting a `struct Location *` parameter.

5\. `nextLoc = player->loc;` copies the values of the player's location into `nextLoc`. The two structures are independent, so modifying `nextLoc` does not change `player->loc`.

6\. `movePlayer()` creates a temporary `Location` to calculate the new position without changing the player's original location. If the move is legal, the new location is copied into `player->loc`; otherwise, the original location remains unchanged.
