# Short Concept Answers

1. double quiz[3]; declares an array named quiz with three double elements.
2. The valid indices are 0 through 9.
3. The last stored index is count - 1.
4. Capacity is how many elements the array can hold. The number entered is how many of those elements the program is using.
5. Accessing an out-of-bounds index causes undefined behavior. The program might produce a strange value, crash, or appear to work.
6. No. The elements of a local int nums[5]; have not been initialized.
7. The values are 6, 2, 0, 0. When an initializer is present, the remaining elements are set to zero.
8. A checker compares 7 / 2 = 3 pairs for 7 values and 8 / 2 = 4 pairs for 8 values.
9. An average divides the sum by the count. If the count is 0, the program would divide by zero.
