# Short Concept Answers

1. The address of a variable identifies the memory location where the variable is stored.
2. `int *p;` declares a pointer variable named `p` that can store the address of an `int` variable.
3. The address-of operator `&` obtains the address of a variable. For example, `&x` gives the address of `x`.
4. The dereference operator `*` accesses the value stored at the address held by a pointer.
5. `p` stores the address of an integer, while `*p` accesses the integer stored at that address.
6. `p = &a;` stores the address of `a` in `p`, making `p` point to `a`.
7. `*p = 20;` changes the value of `a` to 20 because `p` points to `a`.
8. `q = p;` copies the address stored in `p` into `q`. Both pointers then point to the same location.
9. Yes. Two or more pointers can store the same address and point to the same variable.
10. `p = &b;` makes `p` point to `b`. `*p = b;` stores the value of `b` in the variable that `p` points to, assuming `p` is a valid pointer.
11. An uninitialized pointer contains an indeterminate address. Dereferencing it causes undefined behavior, which may crash the program or produce unpredictable results.
12. Passing `x` passes its value, while passing `&x` passes its address. The function can use the address to modify the original variable.
13. The pointer parameter stores the address of the original variable. Dereferencing the pointer allows the function to modify that variable directly.
14. Modifying a regular parameter changes only the local copy. Modifying a variable through a pointer parameter can change the original variable in the calling function.
15. Pointer parameters allow a function to modify variables in the calling function and produce multiple results without directly returning them.
16. A function can accept multiple pointer parameters and store different results through them. For example, `*sum = a + b;` and `*product = a * b;`.
17. We pass the addresses so that `swap()` can access and exchange the original values rather than modifying only local copies.
18. `p = q;` copies the address stored in `q`, not the value pointed to by `q`. Both pointers then point to the same location.
19. Yes. A `void` function can modify variables in `main()` by receiving their addresses as pointer parameters and dereferencing those pointers.
20. `*result = a + b;` stores the sum in the variable pointed to by `result`. `result = a + b;` attempts to assign an integer to the pointer itself instead of updating the intended variable.
