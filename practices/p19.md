## Practice 2: Modifying an Array of Structs

What is the exact output? Explain why the original array changes.

```cpp
struct Point {
    double x;
    double y;
};

void movePoints(struct Point pts[], int size) {
    for (int i = 0; i < size; i++) {
        pts[i].x += 2.0;
        pts[i].y += 3.0;
    }
}

int main(void) {
    struct Point points[2] = {
        {1.0, 4.0},
        {3.0, 6.0}
    };

    movePoints(points, 2);

    for (int i = 0; i < 2; i++) {
        printf("%.1f %.1f\n", points[i].x, points[i].y);
    }

    return 0;
}
```

## Practice 3: Passing a Single Struct vs. an Array of Structs

What is the exact output? Explain why `points[0]` behaves differently when passed to `changePoint()` compared to passing the entire array to `changeAll()`.

```cpp
struct Point {
    int x;
    int y;
};

void changePoint(struct Point p) {
    p.x = 100;
    p.y = 200;
}

void changeAll(struct Point pts[], int size) {
    for (int i = 0; i < size; i++) {
        pts[i].x += 10;
    }
}

int main(void) {
    struct Point points[2] = {
        {1, 2},
        {3, 4}
    };

    changePoint(points[0]);
    changeAll(points, 2);

    printf("%i %i\n", points[0].x, points[0].y);
    printf("%i %i\n", points[1].x, points[1].y);

    return 0;
}
```

## Practice 4: Passing a Pointer to a Struct

```cpp

    double x;
    double y;
};

void init_Point(struct Point *p, double x, double y) {
    p->x = x;
    p->y = y;
}

    struct Point points[2] = {
        {0.0, 0.0},
        {0.0, 0.0}

    return 0;
}
```

6. What is the difference between `struct Point p` and `struct Point *p` as function parameters?
7. What is the difference between the `.` and `->` operators? When should each be used?
8. Why do we use `&pts[i]` when passing a single struct element to a function that expects a pointer?
9. What does `const struct Point pts[]` mean? Can the function modify the elements?
10. Why don't array-of-struct parameters specify the number of elements inside the brackets `[]`?
11. Can a struct contain an array of other structs? Give an example.
12. Given a `struct Triangle` containing `struct Point pt[3]`, how would you access the `y` coordinate of its third point if the Triangle variable is named `tri`?
