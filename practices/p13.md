# Coding Practice

## Practice 13: Rectangle Calculator

<pre>
struct Rectangle {
    float width;
    float height;
};
</pre>

Write the following functions:

<pre>

</pre>

2. Store them in a structure variable.
3. Pass the structure to both functions.
4. Print the area and perimeter.

<pre>

Enter height: <b>3</b>

Your program should:

2. Pass both structures to `addTime()`.
3. Add the hours, minutes, and seconds.
4. Convert every 60 seconds into 1 minute and every 60 minutes into 1 hour.
5. Return a new `struct Time` containing the result.
6. Display the result using `displayTime()`.

Assume the entered minutes and seconds are between 0 and 59.

<pre>
Enter time 1 (hours minutes seconds): <b>1 45 50</b>
Enter time 2 (hours minutes seconds): <b>2 30 25</b>

Total time:
4 hours 16 minutes 15 seconds
</pre>

## Practice 17: Bank Account

Define a structure:

<pre>
struct BankAccount {
    int accountNumber;
    float balance;
};
</pre>

Write the following functions:

<pre>
void displayAccount(struct BankAccount a);

struct BankAccount deposit(
    struct BankAccount a,
    float amount
);

struct BankAccount withdraw(
    struct BankAccount a,
    float amount
);
</pre>

Your program should:

1. Read an account number and initial balance.
2. Read a deposit amount and update the account using `deposit()`.
3. Read a withdrawal amount and update the account using `withdraw()`.
4. Display the final account information.
5. Reject negative deposit or withdrawal amounts.
6. If the withdrawal exceeds the balance, leave the balance unchanged.

Each function must use the structure as a parameter, and the deposit and withdrawal functions must return the updated structure.

<pre>
Enter account number: <b>1001</b>
Enter initial balance: <b>500</b>
Enter deposit amount: <b>200</b>

Account Number: 1001
Final Balance: 550.00
</pre>
