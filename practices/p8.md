# Practice 1: Print a Rectangle

Ask for a width and height. Use nested loops to print a rectangle of asterisks.

### Example output

<pre>
Enter width: <b>5</b>
Enter height: <b>3</b>
*****
*****
*****
</pre>

### Starter code

<pre>
for (int row = 1; row &lt;= height; row++) {
    for (int col = 1; col &lt;= width; col++) {
        // Print one asterisk
    }

    // Print a newline
}
</pre>

## Practice 6: Fix the Nested Loops

This program should print 3 rows and 5 columns of asterisks. Find and correct the mistakes.

<pre>
#include &lt;stdio.h&gt;

int main()
{
    int row;
    int col;

    for (row = 1; row &lt;= 3; row++) {
        for (col = 1; row &lt;= 5; col++) {
            printf("*");
            printf("\n");
        }
    }

    return 0;
}
</pre>

Look carefully at:

* The inner loop condition
* The placement of the newline
* The variables used by each loop

## Practice 7: Read and Repeat a Character

### Example output

<pre>

## Practice 10: Full Lecture Rehearsal

Write a program that:

1. Asks for a character.
2. Asks for a triangle height.
3. Prints a growing triangle using that character.
4. Asks whether the user wants another triangle.
5. Repeats when the user enters `y` or `Y`.

### Example output

<pre>
Enter a character: <b>@</b>
Enter height: <b>4</b>
@
@@
@@@
@@@@

Create another triangle (y or n)? <b>y</b>

Enter a character: <b>+</b>
Enter height: <b>3</b>
+
++
+++

Create another triangle (y or n)? <b>n</b>

Practice complete.
</pre>

### Requirements

* Use a `while` loop to repeat the program.
* Use nested `for` loops to print each triangle.
* Use `char` variables for the symbol and answer.
* Accept both `y` and `Y`.
