
# Short Concept Answers

1. A pointer to a structure is a pointer that stores the memory address of a structure variable.
2. `struct Point *p;` declares a pointer named `p` that can store the address of a `struct Point` variable.
3. `struct Point *p = &a;` stores the address of structure `a` in `p`, making `p` point to `a`.
4. The `->` operator accesses a field of a structure through a pointer. For example, `p->x` accesses the `x` field.
5. `a.x` accesses the `x` field directly, while `p->x` accesses the field through a pointer to the structure.
6. `p->x = 20;` changes the `x` field of structure `a` to 20 because `p` points to `a`.
7. `p->x` and `(*p).x` are equivalent. Both access the `x` field of the structure pointed to by `p`.
8. We use `&a` to pass the address of structure `a` to a function that expects a `struct Point *` parameter.
9. `struct Point p` passes a copy of the structure, while `struct Point *p` passes a pointer that allows the function to modify the original structure.
10. No. Passing a structure by value creates a copy, so modifying the parameter does not change the original structure.
11. The pointer stores the address of the original structure. The function can use `->` to access and modify its fields directly.
12. `void movePoint(struct Point *p, int dx, int dy);` declares a function that receives a pointer to a `Point` structure and two integers. It returns no value but can modify the original structure.
13. We use `p->x` because `p` is a pointer to a structure. The `.` operator is used with a structure variable, while `->` is used with a structure pointer.
14. Yes. Two or more pointers can store the same address and point to the same structure.
15. `q = p;` copies the address stored in `p` into `q`. Both pointers then point to the same structure.
16. `b = a;` copies the field values into a separate structure, while `q = p;` copies an address so both pointers refer to the same structure.
17. An uninitialized structure pointer contains an indeterminate address. Dereferencing it causes undefined behavior, which may crash the program or produce unpredictable results.
18. `const struct Point *p` declares a pointer to a constant `Point` structure. Its fields can be read but cannot be modified through `p`.
19. No. The `const` qualifier prevents modifying `p->x` or other fields through that pointer.
20. Yes. A `const struct Point *p` parameter allows the function to read `p->x` and `p->y` without modifying them.
21. Using `const` prevents accidental changes to the structure and indicates that the function only reads its data.
22. Encapsulation is the programming technique of defining a structure type and implementing functions that operate on instances of that structure.
23. Functions such as `movePoint()` and `printPoint()` demonstrate encapsulation by organizing operations on a `Point` structure into separate functions.
24. Yes. A `void` function can modify a structure in `main()` by receiving its address through a pointer parameter and changing its fields using `->`.
25. Structure reference parameters allow functions to modify original structures without copying them. They make programs more efficient and help organize operations on structures into reusable functions.
