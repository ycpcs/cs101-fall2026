# Read the Code

## Practice 1: Pointer Basics

What is the exact output? Which variable does `p` point to?

<pre>

printf("%i\n", *p);

a = 25;

</pre>

<pre>

## Practice 4: Changing What a Pointer Points To

<pre>

</pre>

## Practice 5: Pointer Assignment

What is printed? Does `q = p` copy the value of `a` or its address?

<pre>

int b = 9;

int *p = &a;
int *q = &b;

q = p;
*q = 50;

printf("%i %i\n", a, b);
printf("%i %i\n", *p, *q);
</pre>

## Practice 6: Pointer Parameters

What is the exact output? Why does `x` change?

<pre>
void addFive(int *p) {
    *p = *p + 5;
}

int main(void) {
    int x = 10;

    addFive(&x);

    printf("%i\n", x);

    return 0;
}
</pre>

## Practice 7: Value vs. Pointer Parameters

What is the exact output? Explain why the two functions behave differently.

<pre>
void changeA(int x) {
    x = 100;
}

void changeB(int *p) {
    *p = 100;
}

int main(void) {
    int a = 5;
    int b = 5;

    changeA(a);
    changeB(&b);

    printf("%i %i\n", a, b);

    return 0;
}
</pre>

# Coding Practice

## Practice 15: Increase a Number

Write a function:

<pre>
void increase(int *p, int amount);
</pre>

Your program should:

1. Read an integer and an amount.
2. Pass the address of the integer to `increase()`.
3. Add the amount to the original variable through the pointer.
4. Print the updated value in `main()`.

<pre>
Enter a number: <b>10</b>
Enter amount: <b>7</b>
Updated number: 17
</pre>

## Practice 16: Swap Two Numbers

Write a function:

<pre>
void swap(int *a, int *b);
</pre>

Your program should:

1. Read two integers.
2. Pass their addresses to `swap()`.
3. Exchange their values using a temporary variable.
4. Print the values before and after swapping.

The `swap()` function must have return type `void`.

<pre>
Enter first number: <b>5</b>
Enter second number: <b>12</b>

Before swap: 5 12
After swap: 12 5
</pre>

## Practice 17: Calculate Sum and Product

Write a function:

<pre>
void calculate(int a, int b, int *sum, int *product);
</pre>

Your program should:

1. Read two integers.
2. Call `calculate()` with the two integers and the addresses of two result variables.
3. Store the sum and product through the pointer parameters.
4. Print both results in `main()`.

Do not use global variables.

<pre>
Enter first number: <b>6</b>
Enter second number: <b>4</b>

Sum: 10
Product: 24
</pre>

## Practice 18: Find Minimum and Maximum

Write a function:

<pre>
void findMinMax(int a, int b, int c,
                int *min, int *max);
</pre>

Your program should:

1. Read three integers.
2. Pass the three values and the addresses of two result variables to `findMinMax()`.
3. Find the smallest and largest values.
4. Store the results through the pointer parameters.
5. Print the minimum and maximum in `main()`.

Your program should also work when some values are equal or all values are negative.

<pre>
Enter three numbers: <b>8 -3 12</b>

Minimum: -3
Maximum: 12
</pre>

## Practice 19: Convert Seconds

Write a function:

<pre>
void convertSeconds(int total,
                    int *hours,
                    int *minutes,
                    int *seconds);
</pre>

Your program should:

1. Read a nonnegative number of seconds.
2. Pass the total and the addresses of three result variables to `convertSeconds()`.
3. Convert the total into hours, minutes, and remaining seconds.
4. Store all three results through pointer parameters.
5. Print the results in `main()`.

<pre>
Enter total seconds: <b>3675</b>

Hours: 1
Minutes: 1
Seconds: 15
</pre>

## Practice 20: Update a Bank Balance

Write the following functions:

<pre>
void deposit(float *balance, float amount);

int withdraw(float *balance, float amount);
</pre>

Your program should:

1. Read an initial balance.
2. Read a deposit amount and update the balance using `deposit()`.
3. Read a withdrawal amount and update the balance using `withdraw()`.
4. Reject negative transaction amounts.
5. Reject withdrawals that exceed the available balance.
6. Have `withdraw()` return 1 if the withdrawal succeeds and 0 otherwise.
7. Print the final balance in `main()`.

Both functions must modify the balance through a pointer rather than returning a new balance.

<pre>
Enter initial balance: <b>500</b>
Enter deposit amount: <b>200</b>
Enter withdrawal amount: <b>150</b>

Withdrawal successful.
Final balance: 550.00
</pre>

8. What happens when we assign one pointer variable to another using `q = p;`?

12. What is the difference between passing `x` and passing `&x` to a function?
13. Why can a function with an `int *p` parameter modify a variable in the calling function?
14. What is the difference between modifying a regular parameter and modifying a variable through a pointer parameter?
15. Why might a function use pointer parameters instead of returning a value?
16. How can a function produce two or more results using pointer parameters?
17. In `void swap(int *a, int *b);`, why do we pass the addresses of the variables?
18. Does assigning `p = q;` copy the value pointed to by `q`, or the address stored in `q`?
