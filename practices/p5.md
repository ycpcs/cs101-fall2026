## Coding Practice

### 1. Positive or Negative

Write a program that asks the user to enter an integer.

- If the number is greater than or equal to `0`, print `"The number is nonnegative."`
- Otherwise, print `"The number is negative."`

Example:

<pre>
Enter an integer: <b>-5</b>
The number is negative.
</pre>

### 2. Temperature Message

Write a program that asks the user to enter the temperature.

- Above `80`: print `"It is hot outside."`
- From `50` through `80`: print `"It is a nice day."`
- Below `50`: print `"It is cold outside."`

Use an `if/else if/else` statement.

### 3. Grade Checker

Write a program that asks the user to enter a test score.

- `90` or higher: print `"Excellent"`
- From `70` through `89`: print `"Passing"`
- Below `70`: print `"Needs improvement"`

### 4. Simple Animal Classifier

Ask the user:

<pre>
Do you have feathers? (1=yes, 0=no)
</pre>

If the answer is yes, ask:

<pre>
Can you fly? (1=yes, 0=no)
</pre>

Print the appropriate result:

- Has feathers and can fly: `"You might be a bird."`
- Has feathers and cannot fly: `"You might be a penguin."`
- Does not have feathers: `"You are not a bird."`

Use nested `if/else` statements.

### 5. Coin Toss

Write a program that simulates a coin toss.

Use the following expression to generate either `0` or `1`:

```cpp
rand() % 2
```

- If the result is `0`, print `"Heads"`
- Otherwise, print `"Tails"`

Include the following libraries:

```cpp
#include <stdlib.h>
#include <time.h>
```

Seed the random-number generator once near the beginning of `main`:

```cpp
srand(time(0));
```

### 6. Rain Simulator

Write a program that asks the user to enter the chance of rain as a percentage.

Generate a random number from `0` through `99`.

- If the random number is less than the chance of rain, print `"It is raining."`
- Otherwise, print `"No rain today."`

Example:

<pre>
Enter the chance of rain: <b>60</b>
It is raining.
</pre>

### 7. Predict the Output

```cpp

if (temperature > 80) {
    printf("Hot\n");
}
else if (temperature >= 50) {
    printf("Comfortable\n");
}
else {
    printf("Cold\n");
}
```

### 10. Find the Mistake

The following code is supposed to print `"A"` for scores of `90` or higher and `"B"` for scores from `80` through `89`.

What is wrong with the code, and how should it be fixed?

```cpp
if (score >= 80) {
    printf("B\n");
}
else if (score >= 90) {
    printf("A\n");
}
else {
    printf("Below B\n");
}
```
