## Practice 6: Predict the Flag

What is printed? At which value of i is the first mismatch found?
<pre>

int palindrome = 1;

for (int i = 0; i < 6 / 2; i++) {
    if (nums[i] != nums[6 - 1 - i]) {
        palindrome = 0;
    }
}

printf("%i\n", palindrome);
</pre>

## Practice 9: Checking the Count

This should accept counts from 1 through MAX_NUMS.
<pre>
#define MAX_NUMS 20

int nums[MAX_NUMS];
int count;

printf("How many values? ");
scanf("%i", &count);

if (count < 0 && count > MAX_NUMS) {
    printf("Invalid count\n");
    return 1;
}

for (int i = 0; i < count; i++) {
    scanf("%i", &nums[i]);
}
</pre>
